# homebrew-tap

Homebrew formulae for [moca](https://github.com/adeotek/moca) — a coding agent in one static Go binary.

## Install

```bash
brew install adeotek/tap/moca
```

## Upgrade

```bash
brew upgrade moca
```

`moca update` **refuses** to replace a Homebrew-installed copy and points at `brew upgrade` instead: a self-updating binary leaves a stale Cellar entry, a broken symlink, and a version Homebrew's bookkeeping then undoes. `moca update --force` is there if you are deliberately leaving Homebrew behind.

## Uninstall

```bash
brew uninstall moca && brew untap adeotek/tap
```

## How these formulae are produced

Not by hand. `Formula/moca.rb` is generated by `scripts/release/render-homebrew-formula.py` in the [moca repository](https://github.com/adeotek/moca), which reads the release's own `checksums.txt` — so the URLs and the four sha256 sums always match the release the formula names. A formula installs a prebuilt tarball only when one exists, which is why moca's release publishes darwin (arm64, x86_64) alongside linux.
